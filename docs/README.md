## 현재 운영 기준

- 서비스: [에움길.한국](https://에움길.한국), Keycloak: `auth.greedylabs.kr`의 `eumgil` realm.
- 실데이터 카탈로그와 사용자 DB를 사용한다. 기본 자연어 매칭은 테마 키워드 기반이며 실 LLM은 운영에 사용하지 않는다.
- data.go.kr 15종은 공통 키 하나와 각각의 활용 승인, 도로공사 1종은 별도 키를 사용한다.
- 공공 집중률은 일별 상대 예측, 시간대별 혼잡은 자체 추정이다. 현장 인원 측정값으로 표시하지 않는다.
- 무장애 안내 보유는 개인의 실제 이용 가능 인증이 아니다. 원문의 제약과 미제공 상태를 보존한다.
- 지도 점선은 방문 순서다. Kakao Mobility 연동은 진행하지 않으며 OSRM 운영은 검토 단계다.

문서를 수정할 때는 같은 상태 설명을 여러 파일에 누적하지 않는다. 기능 계약은 해당 문서에, 배포 커밋·검증 수치는 검증 기록에 갱신한다. 아직 실행하지 않은 검사나 운영 배포를 완료로 쓰지 않는다.
