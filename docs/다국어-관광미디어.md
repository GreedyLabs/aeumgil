# 다국어와 관광 미디어

## 사용자 흐름

로그인 여부와 관계없이 PC 사이드바와 모바일 상단에서 한국어·영어·중국어 간체/번체·일본어·독일어·프랑스어를 선택한다. `eumgil.lang` 쿠키를 1년간 유지하며 서버 렌더링의 `html.lang`, 화면 문구, 관광정보 요청, Keycloak `ui_locales`가 같은 값을 사용한다. 별도 언어 URL이나 자동 번역 모델은 사용하지 않는다.

목적을 한 줄로 입력하면 7언어의 여행 단어 사전으로 테마를 찾는다. 추천·지역 테마·여행지에서 코스를 비교하고 개인 일정을 편집하는 기존 흐름을 유지한다. 선택 언어를 바꿔도 기존 검색어, 일정의 날짜·순서·체류시간과 사용자 제목·메모는 보존한다.

다른 탭에서 언어를 바꾼 뒤 돌아오면 유효한 언어 쿠키를 동기화한다. 교통·행사·방문통계처럼 나중에 도착하는 서버 영역은 요청 당시 언어로 먼저 복원하고 새 서버 응답에서 갱신한다. 사용자 입력 상태와 늦은 서버 화면의 언어를 같은 순간에 강제로 교체하지 않는다.

## 번역의 경계

- UI와 에움길 편집 테마의 제목·소개·계획 유의사항은 정적 번역 사전을 사용한다. 외국어가 길어져도 같은 카드·입력·메뉴 규칙으로 줄바꿈한다.
- 관광공사 외국어 서비스는 `EngService2`, `ChsService2`, `ChtService2`, `JpnService2`, `GerService2`, `FreService2`다. 강원 법정동 `51`의 전체 목록을 공유한다.
- 언어마다 `contentId`가 다르다. 국문 정본과 **이름·300m 이내 좌표·단일 후보**가 모두 맞는 경우만 연결한다. 가까운 다른 시설이나 부분 이름을 동일 장소로 추측하지 않는다. 검토된 복합 이름 예외는 ID·정식 이름·지역·좌표 범위를 제한한 공통 별칭 파일로 관리한다.
- 이름·주소는 목록에서, 소개·운영 안내는 해당 외국어 상세에서 보강한다. 원문 ID·좌표·지역 필터·개인 코스 참조 ID는 바꾸지 않는다. 없는 설명은 한국어/기존 영어 원문과 제공 범위 안내를 유지한다.
- 사용자 이름·소개·리뷰·개인 코스 제목·메모를 UI 사전으로 번역하거나 저장값에 다시 쓰지 않는다. 법률 문서·도로 구간명·공공 원천 안내의 모든 내용이 번역되었다고 표시하지 않는다.

## 관광사진과 오디오

장소·행사 상세에서 본문과 별도의 서버 Suspense로 미디어를 불러온다. 목록 카드·테마 후보 전체에 사진 상세 요청을 발생시키지 않는다.

관광사진은 `PhotoGalleryService1/gallerySearchList1`을 사용한다. 장소명과 촬영 지역을 함께 검증하고 사진마다 촬영자·촬영월·원천 링크·공공누리 제1유형을 표시한다. 출처를 확인할 수 없는 일반 인터넷 이미지를 대신 넣지 않는다. 기존 TourAPI 사진도 유지한다.

오디는 장소 좌표와 이름을 확인한 뒤 동일 `stid`의 언어별 해설을 연결한다. 원천 언어는 한국어·영어·중국어 간체·일본어다. 번체·독일어·프랑스어에서 해당 음성을 번역된 것처럼 표시하지 않으며 미지원 안내를 제공한다. HTTPS 음원이 있는 항목만 기본 음성 플레이어를 제공하고 `preload=none`, 자동재생 없음으로 시작한다. 음원이 없고 대본이 있으면 대본을 읽을 수 있으며 공식 오디 링크를 함께 제공한다.

## 캐시·데이터 경계

| 자료                                   | 보관                                        |
| -------------------------------------- | ------------------------------------------- |
| 언어별 외국어 관광 목록·상세           | 언어와 서비스/ID별 24시간 메모리+파일       |
| 관광사진·오디오/대본                   | 장소/언어별 24시간, 오류는 짧게 재시도 제한 |
| 외국어 검색용 공개 국문 후보           | 5분 서버 메모리                             |
| 개인 코스 장소 검색의 음식점/숙소 목록 | 종류·언어별 5분 서버 메모리                 |

동일 요청을 합치고 실패를 24시간짜리 정상 빈 데이터로 확정하지 않는다. 공유 Repository에 사용자 언어를 보관하지 않으며 검색어·사용자 기록은 공유 캐시 대상이 아니다. 외국어 검색에서 일치한 정본 ID는 DB의 기존 지역·분류·무장애 조건과 합쳐 24개씩 반환한다.

## 인증 화면

Keycloak은 기존 `auth.greedylabs.kr/realms/eumgil`을 사용한다. 테마 소스의 메시지·CSS와 Gitops 복사본을 함께 변경하고 realm의 Supported locales를 같은 7개 코드로 활성화한다. 새 인증 서버·realm·Google 자격증명은 만들지 않는다. 로그인·등록·재설정·정책 링크는 기본 Keycloak 폼과 번역을 상속하고 에움길 고유 문구만 보강한다. 실제 적용 여부와 검사는 [검증 기록](검증.md), 배포 방법은 [인증 테마 안내](../infra/keycloak/THEME.md)를 따른다.

API 신청 링크와 승인 범위는 [공공 API 신청 가이드](공공API-신청가이드.md), 목적 입력의 한계는 [자연어 매칭](자연어-매칭.md)에 정리한다.
