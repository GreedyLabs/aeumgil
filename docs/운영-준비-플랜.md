# 에움길 운영 준비 플랜 (Production Readiness Plan)

> **이 문서의 목적**: 공모전 제출 + 실제 운영을 위해 남은 작업을 추적한다.
> 어떤 AI Agent/개발자가 와도 이 문서만 보고 작업을 이어갈 수 있도록,
> 각 항목에 **문제 → 근거(파일:라인) → 할 일 → 완료 기준(DoD) → 검증 방법**을 적는다.
>
> **사용 규칙**
> - 작업 완료 시 체크박스를 채우고 날짜를 남긴다. (예: `- [x] ... ✅ 2026-07-15`)
> - 항목을 진행하다 새 이슈를 발견하면 해당 섹션에 같은 형식으로 추가한다.
> - 우선순위: **P0** = 제출·운영에 필수(미해결 시 사고/불능) / **P1** = 운영 품질(첫 주 내) / **P2** = 개선(여유 시).
> - 마일스톤 완료 시 [CLAUDE.md](../CLAUDE.md) "진행 상태" 섹션도 함께 갱신한다.
