2026-09-05 기준. 로컬은 루트 `.env`, 배포는 Dockhand 스택 환경변수를 사용한다. 같은 값이 중복되던 공공 API 키 4개는 하나로 합치고 앱 URL도 `AUTH_URL`만 남겼다. `.env.example`에는 실제 필요한 8개만 둔다.

| 변수 | 용도 |
| --- | --- |
| `AUTH_URL` | 로컬 `http://localhost:3000`, 운영 `https://xn--wk0bk16buua.xn--3e0b707e` (= 에움길.한국) |
| `DATABASE_URL` | PostgreSQL 접속 URL. Dockhand는 기존 `shared-db` 네트워크의 `postgres:5432/eumgil_dev` 사용 |
| `AUTH_SECRET` | Auth.js 세션 암호화 키. 기존 운영 값을 유지 |
| `AUTH_KEYCLOAK_ID` | `eumgil` |
| `AUTH_KEYCLOAK_SECRET` | Keycloak eumgil Client의 Credentials 값 |
| `AUTH_KEYCLOAK_ISSUER` | `https://auth.greedylabs.kr/realms/eumgil` |
| `DATA_GO_KR_SERVICE_KEY` | 관광정보·방문자수·집중률·무장애·단기예보·자외선·대기질의 공통 Decoding 키. API별 활용승인은 각각 필요 |

기존 `TOUR_API_SERVICE_KEY`, `TOUR_BIGDATA_SERVICE_KEY`, `KMA_SERVICE_KEY`, `AIRKOREA_SERVICE_KEY`, `NEXT_PUBLIC_APP_URL`, 사용하지 않는 소셜 키·로컬 Keycloak 부트스트랩 키는 앱 `.env`에서 제거했다. Google OAuth Client ID/Secret은 Keycloak에만 저장한다. LLM은 키 없이 heuristic으로 동작한다.

## 배포 자료

- Gitops: `eumgil/docker-compose.yml`, `eumgil/.env.example`, `eumgil/README.md`.
- 앱 루트 `.env.dockhand.local`: **실제 값이 채워진 비공개 배포용 파일**. 기존 운영 컨테이너에서 확인한 DB·인증 값을 보존하고, 통합 API 키와 도로공사 키·새 도메인을 반영했다. Git 및 Docker 빌드 컨텍스트에서 제외한다.
- 로컬 `.env`는 localhost를 유지한다. 운영 값을 로컬 DB 접속 값으로 덮어쓰지 않는다.

GitHub Actions의 기존 `main/dev push → 검사 → GHCR 이미지 → Dockhand 웹훅` 흐름을 유지한다. 두 브랜치 모두 현재 `latest`를 갱신하므로 운영 전환 후 dev를 별도 환경으로 분리할지는 따로 정해야 한다. Dockhand **Build images on deploy는 OFF**다. `latest-<run_number>` 태그로 특정 빌드를 고정할 수 있다.

운영 컨테이너는 통합 키와 새 도메인으로 전환했고 Dockhand 스택 7의 환경변수 8개에 값을 등록했다. 개인 코스 테이블과 검색·무장애 컬럼도 운영 DB에 적용했다. 새 앱은 같은 GHCR 이미지 경로로 배포하며 앱 시작 시 시드나 수집을 실행하지 않는다.

## 도메인 이전

운영은 `https://에움길.한국`이다. OAuth에서는 브라우저가 보내는 ASCII(Punycode) 주소와 일치시킨다.

- Keycloak eumgil Client Valid redirect URI: `https://xn--wk0bk16buua.xn--3e0b707e/api/auth/callback/keycloak`
- Post logout redirect: `https://xn--wk0bk16buua.xn--3e0b707e/*`
- Web origin: `https://xn--wk0bk16buua.xn--3e0b707e`
- Keycloak 테마의 `EUMGIL_APP_URL` 기본값도 같은 운영 주소로 변경했다. 이 변수는 Keycloak compose 전용이다.
- Google 브로커 콜백은 `https://auth.greedylabs.kr/realms/eumgil/broker/google/endpoint`로 유지한다.

원격 Keycloak의 잘못된 콜백 `https://xn--3e0b707e/...`를 전체 도메인으로 수정했다. 새 콜백은 HTTP 200의 에움길 테마, 로그아웃은 새 도메인으로 HTTP 302를 확인했다. DNS와 HTTPS 응답도 확인했다. 실제 계정 로그인 완료까지의 배포 후 왕복은 별도 확인한다.

## 확인 명령

```bash
pnpm --filter @eumgil/web verify:api
pnpm --filter @eumgil/web verify:db
pnpm --filter @eumgil/web verify:keycloak
```

compose `config`는 시크릿을 펼쳐 출력하므로 공유 로그에 남기지 않는다. `/api/health`는 프로세스, `?deep=1`은 DB와 캐시를 검사한다. 외부 API 장애는 헬스체크 실패로 전파하지 않는다.

- 최종 Docker 이미지 빌드, non-root UID 1001 캐시 쓰기, 재시작 후 18개 API 캐시 로드 확인. 같은 상세 2회 재조회에서 캐시 갱신 0건으로 호출 재사용을 확인했다.
