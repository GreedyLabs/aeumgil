# 공공 API 신청 가이드

2026-09-06 공식 명세와 실제 응답 기준이다. 현재 연동은 **16종: 기존 8종 + 외국어 관광정보 6종 + 관광사진·오디오 2종**이다. data.go.kr의 15종은 같은 계정의 **Decoding 일반 인증키**를 `DATA_GO_KR_SERVICE_KEY` 한 곳에 넣는다. Encoding/Decoding은 같은 키의 표현 방식이며, 코드가 원본 키를 한 번 인코딩한다. 각 API의 활용신청은 별도로 필요하다. 도로공사는 별도 키다.

## 외국어 관광정보 6종

각 서비스의 현재 호출은 `areaBasedList2`, `detailCommon2`, `detailIntro2`다. 아래 API를 각각 신청하며 추가 환경변수는 필요하지 않다. 화면 언어 선택지는 한국어를 포함해 7개이고, 공식 관광 본문 제공 언어와 UI 문구 번역을 구분한다.

번체·불어는 공공데이터포털에서 표의 정확한 이름으로 찾는다. 서비스별 명세는 [한국관광공사 TourAPI](https://api.visitkorea.or.kr/)에서도 확인할 수 있다. 6종 모두 공통 키로 실제 정상 응답을 확인했다.

국문과 외국어의 `contentId`는 같지 않다. 언어별 강원 목록을 완전히 받은 뒤 **정규화한 이름이 일치하고 좌표가 300m 이내인 단일 후보**만 기존 장소에 연결한다. 가장 가까운 시설이나 이름의 일부만 겹치는 다른 장소를 연결하지 않는다. 일치 후보가 없거나 모호하면 공식 외국어 정보 미제공으로 안내하고 원문을 유지한다. 언어별 공식 명칭은 장소 검색에도 사용한다.

복합 시설명과 원천 명칭이 다른 경우에는 검토한 별칭만 공유한다. 현재 “강릉 오죽헌·시립박물관”의 “오죽헌” 별칭은 카탈로그 ID·국문명·강릉 지역·기준 좌표를 함께 확인한 경우만 미디어와 외국어 정보 연결에 사용한다.

상세 조회에는 확인한 외국어 `contentId`를 사용한다. `detailCommon2`는 `contentTypeId`를 보내지 않고, `detailIntro2`에는 외국어 응답의 `contentTypeId`를 사용한다. 국문 분류 코드를 재사용하지 않는다. 명칭만 있고 소개·운영 정보가 없는 부분 응답도 항목별로 구분한다. 사용자 리뷰와 원문 관광안내를 자동 번역한 것으로 표시하지 않는다.

| ----------------------------------------------------------------------------------------- | ----------------------------------------- | ------------------------------------------------------------------- |
| [한국관광공사 관광사진 정보\_GW](https://www.data.go.kr/data/15101914/openapi.do)         | `PhotoGalleryService1/gallerySearchList1` | 장소가 확인된 추가 사진 최대 6장·촬영자·촬영 장소/월·출처·이용 조건 |
| [한국관광공사 관광지 오디오 가이드 정보](https://www.data.go.kr/data/15101971/openapi.do) | `Odii/storyLocationBasedList`             | 장소 해설 최대 8개·원어 대본·제공되는 음성 파일·공식 오디 링크      |

사진은 별도 `galContentId`를 사용하며 관광지 공통 ID와 좌표를 제공하지 않는다. 사진 제목과 촬영지의 강원 시군을 함께 확인해 연결한다. 사용 불가 표시가 있거나 장소 연결이 불확실한 사진을 제외하고, 대표 사진이 없다고 다른 지역 사진으로 채우지 않는다. [관광사진 API의 공공누리 제1유형 조건](https://www.data.go.kr/data/15101914/openapi.do)에 따라 촬영자·한국관광공사·출처 링크를 표시한다. 촬영자나 날짜를 제공하지 않으면 만들지 않는다. 이 조건을 기존 TourAPI의 모든 이미지에 일괄 적용하지 않는다.

오디는 1km 주변에서 자료를 조회한 뒤 장소 이름과 500m 이내 좌표로 한국어 해설을 확인한다. 외국어 해설은 같은 `tid`·`stid`의 자료만 연결한다. 현재 공개 API의 언어 코드는 한국어 `ko`, 영어 `en`, 중국어 간체 `cn1`, 일본어 `jp`다. 번체·독일어·프랑스어 UI에서도 해당 언어의 오디오를 제공한다고 표시하지 않는다.

실제 HTTPS 음성 주소가 있을 때 브라우저 재생 컨트롤을 제공하며 자동 재생과 사전 다운로드를 하지 않는다(`preload="none"`). 음성 주소가 없으면 접어서 읽는 원어 대본과 [공식 오디](https://www.odii.kr/) 링크를 제공한다. 미제공·조회 실패·지원하지 않는 언어를 구분한다. 대본의 HTML은 제거하고 음성을 임의 생성하지 않는다. 미디어는 상세의 별도 서버 영역으로 불러와 기본 장소 정보 표시를 지연시키지 않는다.

2026-09-06 사진 승인 후 오죽헌 검색 정상 응답과 장소가 일치하는 사진 6장을 확인했다. 오죽헌 한국어 해설 3개 중 HTTPS 음성 파일 1개가 있고 나머지는 대본을 제공한다. 영어는 연결된 해설 2개의 대본을 확인했다. 모든 관광지와 언어에 같은 수의 미디어가 있다는 뜻은 아니다.

## 호출 시 주의

- TourAPI 강원 법정동 코드는 `lDongRegnCd=51`이다. 시군구는 `lDongSignguCd` 3자리. 과거 지역 코드와 혼용하지 않는다.
- 시군구 코드 조회: `ldongCode2`에 `lDongRegnCd=51`, `lDongListYn=N`.
- 집중률·방문자수 API의 시군구 코드는 `51150`처럼 5자리이며 TourAPI와 파라미터명이 다르다.
- `detailCommon2`에 예전 YN 플래그를 보내지 않는다. `searchKeyword2`도 지원하지 않는 contentTypeId를 보내지 않고 결과에서 필터링한다.
- 방문자수는 공개 시차가 있으므로 조회한 표본일을 표시한다. 일별 집중률은 상대 예측이며 시간대별 자체 추정치나 실시간 인원수로 표현하지 않는다.
- 고속도로 소통은 노선별 관측 구간 정보다. 현재 여행 코스에 대응한 경로·도착시간 계산과 구분한다.

## 캐시와 검증

날씨·대기질 30분, 도로공사 5분, 자외선 1시간, 집중률 6시간, 관광지 상세·무장애 상세·방문자수 24시간, 행사 1시간 캐시를 사용한다. 외국어 목록·상세·사진·오디오 응답도 24시간 캐시한다. 외국어 목록은 언어별로 공유하므로 검색 카드마다 외부 API를 호출하지 않는다. 미디어는 상세에서만 조회하고 사진 검색·언어별 오디오 요청을 합친다. 정상 빈 결과도 캐시하지만 조회 오류를 정상 미제공으로 24시간 저장하지 않는다. 미디어 실패 재시도는 5분간 제한한다. Docker의 `/app/cache` named volume으로 재시작 후 캐시를 유지한다.

```bash
pnpm --filter @eumgil/web verify:api
node apps/web/scripts/verify-tourism-media.mjs
```

첫 명령은 기존 8종의 실제 응답 요약(JSON), 두 번째는 오죽헌 사진·한국어 오디오의 승인/필드 요약을 출력한다. 키는 노출하지 않으며 미디어 검증은 DB를 변경하지 않는다. 외국어 6종은 목록·표본 상세를 별도로 실검증했다. 마지막 실행 근거는 [검증 기록](검증.md), 설정·배포는 [환경변수와 배포](환경변수-배포.md)를 참고한다.

## 행사 조회 범위

`searchFestival2`는 강원에서 현재 진행 중이거나 앞으로 30일 범위에 겹치는 행사를 조회한다. 목록은 최대 100건이며 원천에 등록되지 않은 행사까지 전수 수집했다고 표시하지 않는다. 행사 상세의 기간·요금·운영 정보와 주변 장소는 앱 내 상세 페이지에서 제공한다.

## 카탈로그 및 무장애 정보 갱신

```bash
pnpm --filter @eumgil/web db:collect:gangwon --apply
pnpm --filter @eumgil/web db:sync:accessibility --apply
```

두 명령 모두 `--apply`를 생략하면 검토만 한다. 2026-09-05 무장애 강원 목록 1,517건·박수근미술관 상세 HTTP 200. 현재 관광지 카탈로그와 contentId가 일치하는 661곳에 안내 보유 상태를 반영했다. 식당·숙소 등 다른 콘텐츠 유형은 이 관광지 수에 포함하지 않는다. `무장애 안내 있음`은 특정 사용자의 이용 가능 판정이 아니다. `없음`, 계단, 대여 수량과 조건을 원문대로 표시하고 미제공 항목은 추정하지 않는다.

반려동물 동반 안내는 국문관광정보의 `detailPetTour2`로 추가할 수 있어 별도 키 신청을 우선할 필요는 없다. 현재 화면에는 연결하지 않았다.
