# 구현 현황과 후속 과제

완료 항목은 현재 코드의 계약을 뜻한다. 마지막으로 운영에서 확인한 릴리스와 테스트 수치는 [검증 기록](검증.md)에 따로 기록한다. 기획 목표·실험·배포 사실을 섞지 않는다.

## 현재 제공하는 기능

| 자연어    | 한 줄 입력·Enter 검색·한글 조합 보호, 키워드·지역·제외 조건과 기간 보조 점수, 일치/부분/미일치 근거·입력 수정, 동등 후보의 저장 관심 분야 보조 정렬            |

## 일정과 취향의 현행 계약

- 추천 코스의 기간 선택은 1~5일이다. 탐색의 기간 필터는 기본 기간이 같은 테마를 고르고, 자연어에 적은 일수는 관련 후보 중 같은 기간을 우선하는 보조 점수와 코스 생성 조건으로 사용한다.
- 공식 관광자료를 참고한 편집 코스는 원문을 그대로 옮긴 상품이 아니다. 실제 DB 장소를 연결해 첫날 점심 이후 도착·마지막 날 오후 관광 종료에 맞춰 재구성하고 원문 링크와 별도 확인 조건을 제공한다. 기본안의 일차·순서·긴 체류를 혼잡 점수만으로 다시 섞지 않는다.
- 동일 일자 관광지·식사·숙소의 연속 이동은 이전 항목 종료 이후에 더한다. 집에서 첫 장소, 숙소에서 다음 날 첫 장소, 마지막 귀가 구간은 별도 확인이 필요하다. 실도로와 영업·예약 검증을 완료한 일정이라고 표시하지 않는다.
- 개인 코스의 날짜는 추천 기간 상한과 독립적이다. 실제 시작·종료일이나 날짜 미정의 양의 일차를 저장할 수 있으며 항목은 최대 30개다. 기간 축소로 벗어나는 장소는 안내하고 저장을 막으며 자동 삭제하지 않는다. 추천 복사는 각 일차의 첫 방문 시각을 보존하며, 개인 편집기에서 날짜별 출발 시각을 수정하거나 기본 하루 출발 시간으로 되돌린다. 날짜·시각은 DB 저장·기존 코스 담기·충돌 초안 복구에서도 유지한다.
- 추천 복사는 점심·숙소 등 항목별 예정 시각도 보존한다. 개인 일정은 이전 방문 종료와 이동 이후, 예정 시각보다 이르지 않게 계산한다. 항목 시각은 수정·해제할 수 있고 수동 추가 장소에는 필수 시각을 만들지 않는다. 출발을 앞당기려면 개별 예정 시각도 함께 검토한다.
- 홈·탐색 첫 노출은 1박·2박 중심에 당일·장기 코스를 섞고 권역 중복을 완화한다. 요청마다 동등 후보를 순환하지만 한 화면의 필터·추가 로딩 순서는 고정한다. 모든 기간의 실제 카탈로그와 자연어 관련성 순위는 유지한다. 구체적인 노출 비율은 [theme-exposure.ts](../apps/web/src/domain/theme-exposure.ts)를 따른다.
- 프로필 여행 취향은 DB에 실제 저장한다. 10개 관심 분야·페이스·동행 모두 선택 사항이며 저장값 복원과 해제를 지원한다. 관심 분야는 명시 조건이 동등한 후보 사이에서, 페이스·동행은 비명시 조건에서만 사용한다. 닉네임·소개 수정은 취향과 분리한다. 사용자 취향을 공용 캐시에 저장하지 않는다.

## 제품 판단 기준

- 저장 취향은 보조 기준이다. 명시한 여행 조건이 우선하며, 미설정 사용자의 취향을 임의로 만들지 않는다. 취향 저장 실패와 실제 추천 적용을 사용자에게 구분해 알려야 한다.
- 목적 입력에서 추천 이유를 이해하고 조건을 고칠 수 있어야 한다. 맞는 테마가 없을 때 일치한 것처럼 안내하지 않는다.
- 지도는 장소를 고르고 방문 순서를 판단하는 데 기여해야 한다. 독립 지도 메뉴를 늘리지 않는다.
- 추천 테마 보관과 개인 일정 저장을 명확히 구분한다. 일정 수정은 로그인 후 소유자 데이터로 보존한다.
- 모바일에서도 입력→판단→편집→저장이 이어져야 하며 과도한 스크롤이나 화면을 가리는 조작으로 끊기지 않아야 한다.
- 카드 선택 강조가 크기·위치 변화를 만들지 않아야 한다. 외부 이동 표시와 공통 메뉴·입력·Select를 일관되게 사용한다.
- 정보 부족·실패·빈 결과를 실제 값과 구분한다. 데이터가 없는 곳의 사진·혼잡·평점·접근 가능성을 만들지 않는다.

## 이번 운영 범위에서 보류한 것

- Kakao Mobility 실경로 연동: 진행하지 않는다.
- OSM 기반 OSRM/Valhalla 서버: 방식 검토만 유지한다. 별도 배포하지 않았다.
- 실 LLM·RAG·멀티모달: 운영 기본 기능이 아니다. 키워드 방식의 품질·한계를 먼저 검증한다.
- Kakao/Naver 소셜 로그인: 운영 제공 범위에 포함하지 않는다.
- 반려동물 동반 상세: TourAPI 추가 오퍼레이션 후보이며 아직 화면에 연결하지 않았다.

학습 실험의 모델·프롬프트·평가 계획은 [별도 학습 문서](ai-eval-course/README.md)에 둔다. 이 목록을 승인 없이 운영 기능 확정으로 바꾸지 않는다.

## 목록 탐색과 홈 교통 개선

- 테마·여행지·개인 코스 장소 검색·행사는 하단에서 이어 읽는다. 테마 추천 순서와 선택한 지도, 편집한 개인 일정은 추가 로딩으로 초기화하지 않는다. 실패 재시도·중복 제거·검색 변경의 늦은 응답 폐기·숨김 검색 탭 요청 중지를 적용한다. 상세 소개의 펼치기 버튼은 유지한다.
- 교통 영역을 홈 하단으로 옮겨 세 고속도로의 구간명·방향·관측속도·시각과 소통 비율을 제공한다. 저속 구간을 우선 표시하고 미측정·오래된 관측을 원활로 바꾸지 않는다. 도로 길이·정체 원인·실시간 개인 경로는 별도 범위다.

## 다국어·관광 미디어

한국어·영어·중국어 간체/번체·일본어·독일어·프랑스어 UI와 편집 테마, 공식 외국어 관광 안내·이름 검색, 사진 갤러리와 오디오/대본을 제공한다. Keycloak 테마도 같은 7개 언어를 사용하되 realm 활성화와 파일 배포는 별도 단계다. 실제 제공·미제공 기준은 [다국어·관광 미디어](다국어-관광미디어.md), 실행·배포 여부는 [검증 기록](검증.md)을 따른다.
